# Arsh Nehal | Portfolio
 
My personal portfolio website, built from scratch with plain HTML, CSS and JavaScript.
 
**Live site:** [arshnehal.vercel.app](https://arshnehal.vercel.app)
 
## What's inside
 
- **About:** who I am and what I build
- **Projects:** SYNC, VisionAI, Pulse, VELLUM Document Studio, a Python AI assistant, Meridian Calendar, APEX and RIVEN
- **Skills:** Python, JavaScript, AI and APIs, computer vision
- **Contact:** GitHub, LinkedIn, YouTube, Reddit and email
## Features
 
- Animated intro and letter-by-letter name reveal
- Liquid blob cursor and click confetti
- 3D tilt project cards with a spotlight effect
- Scroll animations, counters and a progress bar
- Fully responsive and respects reduced-motion settings
- One single file, with no frameworks or build tools
## Run it locally
 
1. Download or clone this repository
2. Open `index.html` in your browser
## Deploy
 
The site is hosted on Vercel. Keep `index.html` in the root of the project and it deploys with no extra settings.
